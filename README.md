# .github

Organization-wide files for [Create Collective](https://github.com/create-collective):

- [`profile/README.md`](profile/README.md): the overview shown on the organization's page.
- [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md),
  [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md) and [`FUNDING.yml`](FUNDING.yml): the defaults for every repository
  that doesn't have its own.
- [`brand/`](brand/): the logo, avatar and colors.
