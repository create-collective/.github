# Brand assets

<img src="mark.svg" width="96" alt="The Create Collective mark">

The mark is two C's, one inside the other and facing opposite ways: Create and Collective. It
shares OpenFlow's navy and cyan, and its ring echoes OpenFlow's.

## Files

| File | Use |
|---|---|
| [`mark.svg`](mark.svg), [`mark.png`](mark.png) | The mark on light backgrounds |
| [`mark-white.svg`](mark-white.svg), [`mark-white.png`](mark-white.png) | The mark on dark backgrounds |
| [`mark-mono.svg`](mark-mono.svg) | One color, for print, embossing and small favicons |
| [`lockup-light.svg`](lockup-light.svg), [`lockup-dark.svg`](lockup-dark.svg) | Mark and wordmark, for light and dark backgrounds |
| [`avatar.svg`](avatar.svg), [`avatar.png`](avatar.png) | Square avatar for GitHub and other profiles (1000 × 1000) |
| [`social-preview.svg`](social-preview.svg), [`social-preview.png`](social-preview.png) | Link preview image (1280 × 640) |

The profile banners are in [`../profile/assets/`](../profile/assets/).

## Colors

| Name | Hex | Use |
|---|---|---|
| Navy | `#1B242C` | The outer C on light backgrounds; avatar background |
| Cyan | `#03B9C9` | The inner C and accents only |
| White | `#FCFCFD` | The outer C on dark backgrounds |

## Type

The wordmark is set in lowercase [Outfit](https://fonts.google.com/specimen/Outfit) SemiBold,
licensed under the SIL Open Font License 1.1, and outlined in these files so they need no font to
display.

## Using the mark

You're welcome to use the mark to link to Create Collective or to talk about our projects. Please
don't change its shape or colors, and don't use it in a way that suggests we made or endorse
something we didn't.
